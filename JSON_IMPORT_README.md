# JSON Import

KARAM now treats JSON as a first-class, provider-neutral test format.

Use the `Import JSON Test` action to choose a `.json` file. The app validates the complete question set and saves it to the same local Test Library/CBT flow used by other tests.

No Gemini account, Canvas link, website, backend, or API is required for this import path.

The question-paper PDF and official answer-key uploads remain separate source inputs for the PDF extraction workflow. A ready-made JSON test does not require either file.
