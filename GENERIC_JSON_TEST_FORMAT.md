# KARAM Generic JSON Test Import

KARAM is provider-agnostic. A test can be generated by any website, AI tool, script, or editor and imported directly as a `.json` file.

Minimum format:

```json
{
  "v": 1,
  "testId": "MY_TEST_001",
  "title": "JEE Main Test",
  "durationMinutes": 180,
  "markingScheme": {
    "MCQ": { "correct": 4, "incorrect": -1, "unattempted": 0 },
    "Numerical": { "correct": 4, "incorrect": -1, "unattempted": 0 }
  },
  "questions": [
    {
      "questionId": "Q1",
      "questionNumber": 1,
      "subject": "Mathematics",
      "section": "A",
      "questionType": "MCQ",
      "questionText": "...",
      "options": ["...", "...", "...", "..."],
      "correctAnswer": "A",
      "chapter": "...",
      "subtopic": "...",
      "concept": "...",
      "difficulty": "Moderate",
      "estimatedTime": 90,
      "solution": {
        "bestSolution": "...",
        "fastestMethod": "...",
        "importantConcept": "...",
        "commonTrap": "...",
        "strategy": "Must Attempt"
      },
      "videoSolution": "https://www.youtube.com/..."
    }
  ],
  "answerKey": []
}
```

Provider-specific fields are ignored safely. The JSON is the only required test-generation input. KARAM does not require Gemini or any specific AI provider.

## Source files

The conversion screen has separate source-file slots for:

- Question Paper PDF
- Official Answer Key PDF/JSON

These source files are kept as inputs for the existing extraction workflow. They are independent from the generic JSON importer.

## Import priority

For a ready-made test, use **Import JSON Test**. It bypasses PDF extraction and Gemini processing and immediately creates the CBT from the validated JSON.
